Expenditure Plan Insights

Two new insights on top of the Plan balances shipped in v1.87: ① Plan vs Actual (is spending tracking the expenditure plan? — hands up / hands down) and ② Plan vs Budget (does the plan cover the budget?). Below are alternative layouts for the dashboard and both reports. Pick one code per group, mix freely, or mark up what you want changed.

The two indicators shared by every layout

Same formulas everywhere — only the presentation differs between the options. Thresholds become GL module settings so Finance can tune them without a deploy.

① Plan vs Actual — execution

Execution % = Total Actual (AP+GRN) ÷ Plan YTD
👍Within plan90 – 110 % of Plan YTD
👎Below plan< 90 % — spending slower than planned
✋Ahead of plan> 110 % — spending faster than planned
—No planline has no uploaded plan (excluded from aggregates)

② Plan vs Budget — coverage

Coverage % = Plan Annual ÷ Annual Budget
●Fully planned95 – 105 % of the annual budget
◔Under-planned< 95 % — shows the plan gap in AED
▲Over-planned> 105 % — plan exceeds the budget
✕Not plannedbudget line with no plan at all

Period basis: both use the page's Budget Year + Accounting Period criteria — execution compares YTD-to-YTD; on Full year it compares annual-to-annual. In the Excel / PDF reports the hand emoji become colored glyphs ▲ ● ▼ (emoji rendering is unreliable in the report fonts); the dashboard keeps the hands. CSV export always carries the raw % and variance columns whichever layout you pick.
